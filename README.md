# 考研政治刷题（开源免费）

一个打开就能用的考研政治刷题网页：**不用注册、没有广告、不联网也能刷**，进度只存在你自己的浏览器里。

自带按科目筛选、错题重刷、多选严格判分（全对才得分），还附了 5 份速查材料。

> ⚠️ **本仓库不包含任何题库数据。** 仓库只自带 6 道示例题用来演示。
> 题目有版权，请把你自己合法取得的题目按下面的格式整理成 `questions.json` 导入使用。

## 怎么用

**方法一：直接打开**
下载本仓库，双击 `index.html` 就能在浏览器里刷示例题。
把你自己的 `questions.json` 放到和 `index.html` 同一个文件夹，再打开页面，就会自动加载你的题库。

**方法二：在页面里导入**
打开页面 → 点右上角「导入题库」→ 选你的 `questions.json` 文件。手机、电脑都行，不用装任何东西。

**方法三：挂到 GitHub Pages（可选）**
把仓库（含你的 `questions.json`）推到 GitHub，开 Pages，就能得到一个手机随时打开的网址。

## 功能

- 按科目筛选：马原 / 毛中特 / 新思想 / 史纲 / 思法（按题库的分类自动生成）
- 单选、多选都支持；**多选必须全对才得分**，少选、多选都算错（和真实考试一致）
- 提交立刻看对错和解析；答错自动进错题本，可「只刷错题」
- 顶部实时统计：已做多少、正确率、错题数
- 进度自动保存在浏览器本地，关掉页面下次接着刷

## 怎么得到题库（三种方法，原料都是你自己合法取得的题目）

本仓库不带题库，但把「自己的题变成题库文件」这一步做成了现成的路，三选一：

**方法一：AI 整理（最省事，手机也能干）**
原料通常就是 **PDF**（自己买的书的电子版、扫描的书页、自己整理的文档）：
把 PDF 文件连同 `tools/AI整理提示词.md` 里的提示词一起发给任何 AI，
它会直接吐出 `questions.json`，存下来导入即可。只有文本没有 PDF 的，把文本粘在提示词后面一样用。

**方法二：转换脚本（题目已经是文字，在电脑上）**
按 `tools/to_questions.py` 开头写的简单文本格式排好（或者用 Excel 存成 CSV），跑一句：

```
python3 tools/to_questions.py 我的题目.txt questions.json
```

就得到题库文件。文本格式长这样，题目之间空一行：

```
分类：马原 单选
题干写在这里（ ）
A. 选项一
B. 选项二
C. 选项三
D. 选项四
答案：A
解析：可省略
```

**方法三：直接手写 JSON**
照下面「题库格式」一节自己拼，适合题量小或程序员。

> 原料边界：请只用你自己买的书、自己整理的资料、自己做的错题。
> 本项目不提供任何题目的下载来源，也请不要把转换好的商业题库文件公开传播。

## 题库格式（questions.json）

一个 JSON 数组，每道题长这样（参照仓库里的 `questions.sample.json`）：

```json
[
  {
    "id": "q1",
    "cat": "我的题库·马原 单选",
    "stem": "题干写在这里（ ）",
    "options": ["选项一", "选项二", "选项三", "选项四"],
    "answer": 0,
    "explanation": "解析写在这里，可省略"
  },
  {
    "id": "q2",
    "cat": "我的题库·马原 多选",
    "stem": "多选题的题干（ ）",
    "options": ["选项一", "选项二", "选项三", "选项四"],
    "answer": [0, 1, 2],
    "explanation": "多选的 answer 是数组，写所有正确选项的序号"
  }
]
```

字段说明：

| 字段 | 说明 |
|---|---|
| `id` | 随便编，别重复就行 |
| `cat` | 分类。写成「来源·科目 单选」这种格式，中间的科目名会自动变成筛选按钮 |
| `stem` | 题干 |
| `options` | 选项数组，序号从 0 开始对应 A B C D |
| `answer` | 单选写一个数字；多选写数字数组 |
| `explanation` | 解析，可不写 |
