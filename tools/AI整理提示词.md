# 用 AI 把你的题目整理成题库文件（提示词模板）

**最常见的原料就是 PDF**（自己买的书的电子版、自己扫描的书页、自己整理的文档）。
现在主流 AI 都能直接读 PDF：把 PDF 文件和下面这段提示词一起发给它就行，
不用自己先转文字。它会直接吐出能导入的 `questions.json`。

题量大的 PDF 一次处理不完就按章节分几次，每次让它接着上次的编号往下编，
最后把几个数组合并成一个文件即可（或者分别导入，分批刷也行，本页面支持多次导入覆盖——注意：重新导入会换掉当前题库，进度按题目 id 保留，建议 id 编号别重复）。

没有 PDF、只有题目文本时同理，把文本粘贴在提示词最后即可。

---

把我下面给的题目文本整理成一个 JSON 数组，格式严格如下，不要输出 JSON 以外的任何内容：

- 每个元素是一道题，字段：id、cat、stem、options、answer、explanation
- id 从 "q1" 开始顺序编号
- cat 写成「我的题库·科目 单选」或「我的题库·科目 多选」，科目按题目内容判断（马原 / 毛中特 / 新思想 / 史纲 / 思法）
- stem 是题干原文，不要改写
- options 是选项数组，顺序对应 A B C D，不要带字母前缀
- answer：单选写一个数字（A=0, B=1, C=2, D=3）；多选写数字数组，如 [0, 2]
- explanation 写解析；原文没有解析就留空字符串
- 原文里认不准的题宁可跳过，并在最后用一行注明跳过了几道
